# Central Top Flow - Página de Login

Bem-vindo à **Central Top Flow**, uma página de login personalizada com estilo moderno, voltada para quem deseja se destacar nas redes sociais.

Este projeto foi criado por **@kaiovini30** com HTML, CSS e JavaScript — e conta com uma experiência visual diferenciada, incluindo um jumpscare com áudio.

## Funcionalidades
- Layout responsivo e estilizado
- Animação com jumpscare ao fazer login
- Áudio ambiente de suspense (Jeff the Killer)
- Uso leve e compatível com dispositivos móveis
- Aviso de cookies e termos

## Demonstração
Veja a página online (GitHub Pages):  
[https://kaiovini30.github.io/TopFlowLogin/](https://kaiovini30.github.io/TopFlowLogin/)

## Como usar
1. Clone o repositório ou baixe os arquivos
2. Abra o `index.html` no navegador
3. Preencha os campos de login e divirta-se com a surpresa!
